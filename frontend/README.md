# Frontend

The React app for Weather-Aware Truck Routing. See the [main README](../README.md) for how the app works, the project structure, and how to run, test and deploy it.

```bash
npm install
npm run dev        # http://localhost:5173, proxies /api to the Django API on :8765
npm test           # Vitest
npm run build      # needs VITE_API_URL, e.g. https://truck-routing-api-mo4g.onrender.com/api/v1
```
